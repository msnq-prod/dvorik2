# New Design Direction

## Принцип

Админка должна ощущаться как рабочее место управляющего магазином: компактно, быстро, без декоративности, с сильной опорой на таблицы, статусы, журналы и подтверждения.

## Новый app shell

- Левый сайдбар на desktop, нижняя/компактная навигация для Telegram mobile.
- Группы меню:
  - Обзор: Главная.
  - Каталог: Товары, Дубли, Импорт.
  - Склад: Склад, Инвентаризация, Маркировки.
  - Команда: График, Пользователи.
  - Контроль: Аудит.
- Вкладки скрываются или блокируются по правам до перехода.
- В topbar: текущий контекст, быстрый поиск, пользователь, режим dev/test, состояние синхронизации.

## Визуальный язык

- Нейтральная рабочая палитра с зеленым как action/accent, красным только для риска.
- Радиус 8px, без вложенных карточек.
- Плотные панели, таблицы и формы; крупный hero не нужен.
- Иконки lucide для действий и навигации.
- Бейджи для статусов, не сырые enum.

## Паттерн самостоятельной вкладки

Каждая вкладка должна иметь:

- собственный page component;
- локальный toolbar;
- основной рабочий блок;
- боковой/нижний блок контекста, если нужен;
- состояния loading/empty/error/no permission;
- проверяемый success/failure feedback;
- минимум технических ID в основном UI;
- ссылки на связанные сущности вместо разрозненных строк.

## Первые итерации реализации

1. Разнести app shell, navigation и страницы из `main.tsx`.
2. Ввести общие компоненты: `PageHeader`, `Toolbar`, `DataTable`, `StatusBadge`, `EmptyState`, `PermissionGate`.
3. Пересобрать вкладки по одной, начиная с `Главная` и `Товары`.
4. После каждой вкладки запускать `npm run check`, при необходимости browser smoke.
