# Scope

## Цель

Пересобрать админскую часть `gpt-version` из монолитного прототипа в набор самостоятельных рабочих вкладок с понятной навигацией, ролью каждой функции и UX/UI, который соответствует складскому WebApp.

## Входит

- Обобщить прошлую реализацию меню и app shell.
- Описать текущую реализацию каждой вкладки актуального сайдбара.
- Зафиксировать UX/UI огрехи по смыслу функции.
- Описать целевую реализацию каждой самостоятельной вкладки.
- Сформировать новый дизайн электронного приложения.
- Реализовать вкладки итерациями после согласованного аудита.

## Не входит

- Возврат к старой CRM лояльности как предметной области.
- Рефактор backend без прямой потребности UI-вкладок.
- Замена текущего стека.

## Источники

- Текущий WebApp: `src/client/src/main.tsx`, `src/client/src/styles.css`.
- API и домен: `src/server/index.ts`, `src/server/domain.ts`, `src/shared/types.ts`.
- Предыдущий аудит: `docs/audits/gpt-version-full-20260626`.
- Старая реализация: `../client/src/components/app-sidebar.tsx`, `../client/src/App.tsx`, `../design_guidelines.md`.
