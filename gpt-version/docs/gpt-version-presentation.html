Рабочий WebApp-прототип для склада, смен, маркировок, импортов и аудита.

React + Express Telegram WebApp SQLite PDF-этикетки
Коротко

Это уже демонстрационный продуктовый прототип, а не только дизайн или ТЗ

В версии есть основные сценарии магазина: товарный каталог, остатки, движения, инвентаризация, график смен, импорт поставок, маркировки и роли пользователей.

Что сделано для Telegram WebApp

InitData auth

Реальный Telegram WebApp использует `window.Telegram.WebApp.initData`.

Test mode

Локальный вход через `?tgUserId=u-admin` и подписанные dev initData.

Ограничение

Production Telegram bot webhooks не входят в этот прототип.

Ограничения версии

Не production

Это свежий рабочий прототип, но не финальная промышленная сборка.

SQLite

Хранение сейчас через SQLite. Перед production нужно утвердить, оставляем SQLite или мигрируем.

Telegram bot webhooks

WebApp auth есть, production webhooks для бота нужно проектировать отдельно.
