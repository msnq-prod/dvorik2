# План реализации

## Этап 0. Подготовка

- добавить `.env.example`;
- добавить миграции Drizzle;
- настроить авторизацию и роли;
- подключить единый формат ошибок и аудит;
- добавить базовые тесты API.

## Этап 1. Персонал и смены

- таблицы сотрудников, точек, смен и назначений;
- API сотрудников и календаря;
- экраны списка сотрудников и расписания;
- проверка пересечений;
- тесты конфликтов и прав доступа.

## Этап 2. Товары и склад

- каталог и категории;
- склады и остатки;
- журнал движений;
- приход, расход, списание, корректировка, перемещение;
- низкие остатки и история товара;
- транзакционные тесты.

## Этап 3. Маркировки

- шаблоны этикеток;
- Code 128 и EAN-13;
- массовое задание печати;
- предпросмотр и PDF;
- история и повторная печать;
- проверка на реальных принтерах.

## Этап 4. Завершение MVP

- дашборд;
- аудит;
- адаптация для планшета;
- резервное копирование;
- пользовательская инструкция;
- приёмочные сценарии.

## Рекомендуемый порядок релизов

1. `0.1` — авторизация, сотрудники, смены.
2. `0.2` — товары и остатки.
3. `0.3` — печать маркировок.
4. `1.0` — аудит, дашборд, эксплуатационная документация.
