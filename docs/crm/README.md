## Границы MVP

В MVP входят:

1. сотрудники и назначение по сменам;
2. каталог товаров и складские остатки;
3. формирование и печать товарных маркировок;
4. авторизация, роли и журнал изменений.

Не входят в MVP:

- расчёт зарплаты и табель рабочего времени;
- закупки и взаиморасчёты с поставщиками;
- кассовые операции и онлайн-касса;
- полноценная CRM продаж;
- мобильное приложение;
- прямая интеграция с конкретной моделью принтера.

Текущие функции лояльности можно сохранить как отдельный модуль, но они не являются частью описанного MVP.
