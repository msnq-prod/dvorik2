## 2. Межблочные источники истины

| Концепт | Владелец | Потребители | Запрещённое дублирование |
| --- | --- | --- | --- |
| Товар, группа, пачка, barcode | B03 | B04–B06, B08 | Saby catalog не перезаписывает Dvorik |
| Общий остаток | B03 stock ledger | B04–B06, B08 | placement не становится отдельным складом |
| Размещение по полкам | B03 placement projection | B04, B09 | инвентаризация не назначает полку расходу |
| Партия и FIFO | B04 | B05, B08 | отчёт не пересчитывает FIFO самостоятельно |
| Фактический расход веса | B05 | B08 | переносы в зал не добавляются повторно |
| Фактическая продажа/выручка | B06 Saby ledger | B08 | расчётная выручка не заменяет факт |
| Расчётная/прогнозная выручка | B05 | B08 | хранится отдельно от Saby actual |
| График и кадровые факты | B07 | B08, B09 | payroll не владеет календарём |
| Зарплатный результат | B07 | B08 | доступ только владельцу |
| Расходы, налог, период | B08 | B09, B10 | закрытый период не меняется без reopen |

| Уведомления | B09 outbox catalog | B03–B08 | transport не содержит бизнес-правила |

## 3. Критические последовательности

### Весовой товар

B04 поставка и партия → B03 общий остаток/полка → B03 перенос пачки в зал → B05
закрытие расхода → B08 FIFO-себестоимость и отчёт.

### Штучный товар

B04 поставка и партия → B06 Saby sale/return → B04 FIFO allocation → B08
товарная прибыль.

### Неизвестная Saby-позиция

B06 durable inbox → общая выручка без stock → B06 admin mapping → backfill
движений → B08 перерасчёт открытого периода.

### Финансовый месяц

B04 себестоимость + B06 выручка + B07 зарплата + B08 расходы/УСН → закрытие 11-го
числа → owner reopen при поздней закупочной цене.

### Премия и налоговые признаки

B07 reference-классификация облагаемой трудовой премии → отдельный management
override владельца → B08 раздельное отображение reference и внутреннего расчёта.

### Cutover без миграции legacy

B03–B09 ручное заведение обязательных начальных данных → B06 Saby mapping и
reconciliation → B10 сверка и ролевой smoke → отключение legacy writes.

## 4. Cross-area stop conditions

- B05 не закрывается без доказательства отсутствия двойного расхода.
- B06 не закрывается без реального API-check и replay позднего возврата.
- B08 не закрывается при смешении actual/estimated/forecast.
- B09 не закрывается без отрицательных permission E2E.
- B10 не закрывается, если любой scope-раздел не имеет acceptance evidence.
