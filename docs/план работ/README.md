# План работ Dvorik

Комплект переводит production-требования в программу работ, которую можно
передать продуктовой команде или подрядчику.

## Основные документы

- `05_НАВИГАЦИЯ.md` — маршрут чтения и выполнения плана по ролям и задачам.
- `00_SCOPE.md` — границы, источники и ограничения.
- `01_ОБЩАЯ_СТРАТЕГИЯ.md` — порядок реализации и контрольные ворота.
- `04_ФАЗЫ_РЕАЛИЗАЦИИ.md` — разделение на доступную сейчас и зависимую от
  внешних данных фазы.
- `02_ORCHESTRATION.md` — независимая проверка субагентом.
- `03_CROSS_AREA_MAP.md` — покрытие scope и межблочные контракты.

- `agents/A01-independent-review/` — материалы независимого субагента.
- `98_НЕЗАВИСИМАЯ_ПРОВЕРКА.md` — итог проверки и внесённые корректировки.

## Реализация

- `фаза-1/README.md` — статус и артефакты доступной сейчас фазы.
- `фаза-1/01_CURRENT_STATE_BASELINE.md` — фактический технический baseline.
- `фаза-1/02_REUSE_REWORK_REMOVE.md` — первичная матрица решений по контурам.
- `фаза-1/03_REGRESSION_BASELINE.md` — воспроизводимая проверка текущего продукта.
