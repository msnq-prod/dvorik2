# A01 Verification Notes

## Run

- `git remote -v`
- `git status --short`
- `git ls-files`
- `sed -n` / `nl -ba` по ключевым файлам.
- `npm run check` in root: failed, `tsc: command not found`.

## Skipped

- Live запуск.
- DB checks.
- Dependency install.

## Residual Risk

Есть незакоммиченные локальные материалы. Их нельзя удалять или переименовывать без решения пользователя.
