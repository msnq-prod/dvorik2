# Scope

## Цель

Разобрать репозиторий `msnq-prod/dvorik2` и подготовить требования для MVP системы управления магазином:

- персонал и смены;
- складские остатки;
- печать товарных маркировок.

## Источники

- ветка `main` репозитория;
- текущие frontend, backend и схема БД;
- `replit.md`, `design_guidelines.md`, `docs/telegram-bot-api.md`;
- три одинаковых DOCX-плана и две текстовые выгрузки из `attached_assets`.

## Допущения

- текущий стек React + Express + Drizzle + PostgreSQL сохраняется;
- маркировка MVP означает обычную этикетку со штрихкодом, не Data Matrix «Честного знака»;
- печать выполняется через PDF;
- одна организация, но модель поддерживает несколько торговых точек и складов.

## Не входит

Реализация кода, зарплата, касса, закупки, интеграции с ЭДО и «Честным знаком».
