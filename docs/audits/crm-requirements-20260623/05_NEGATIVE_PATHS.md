# Negative paths

## Смены

- окончание раньше начала;
- пересечение смен;
- назначение неактивного сотрудника;
- удаление точки с будущими сменами;
- одновременное редактирование двумя менеджерами.

## Склад

- расход больше остатка;
- повторная отправка одной операции;
- перемещение на тот же склад;
- изменение архивного товара;
- сбой между списанием и зачислением при перемещении;
- параллельные движения одного товара.

## Маркировки

- пустой выбор;
- количество 0 или слишком большое;
- некорректный EAN-13;
- отсутствующее обязательное поле шаблона;
- изменение цены между созданием задания и повторной печатью;
- ошибка генерации PDF.

## Доступ

- прямой вызов API без прав;
- заблокированный аккаунт с активной сессией;
- просмотр чужих смен сотрудником.
