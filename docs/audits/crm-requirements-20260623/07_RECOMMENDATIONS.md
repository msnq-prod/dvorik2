# Recommendations

1. Сначала внедрить авторизацию, роли, миграции и аудит.
2. Реализовать персонал и смены как первый независимый вертикальный модуль.
3. Остатки строить на неизменяемом журнале движений и транзакциях.
4. Печать начинать с PDF и Code 128; интеграцию с конкретным принтером делать после проверки оборудования.
5. Не смешивать новые сущности сотрудников с текущей таблицей Telegram-кассиров.
6. Текущую лояльность оставить отдельным модулем либо явно вывести из меню.
