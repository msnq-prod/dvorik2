# Data lineage

## Смена

Форма менеджера → валидация времени и сотрудников → `shifts`/`shift_assignments` → календарь → аудит.

## Остаток

Складская операция → валидация количества и прав → транзакция → `stock_movements` → `stock_balances` → список остатков и дашборд.

Источник правды: журнал движений. `stock_balances` — проверяемый агрегат.

## Маркировка

Карточка товара → выбор шаблона и количества → снимок данных в `label_print_items` → генерация штрихкода/PDF → скачивание → аудит печати.

Источник правды для повторной печати: снимок в задании, а не текущая карточка товара.
