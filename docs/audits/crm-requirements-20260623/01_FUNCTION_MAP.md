# Function map

## Существующая система

| Область | Состояние |
|---|---|
| Навигация | лояльность, пользователи, скидки, кассиры, рассылки |
| Frontend | визуальные страницы с мок-данными |
| Backend | CRUD для сущностей лояльности |
| БД | 10 таблиц, связанных со скидками и Telegram |
| Авторизация | отсутствует |

## Целевые действия

### Персонал

Создать сотрудника → изменить → деактивировать → открыть его смены.

### Смены

Создать смену → назначить сотрудников → проверить пересечения → опубликовать → завершить/отменить.

### Склад

Создать товар → провести движение → пересчитать остаток → открыть историю → показать низкий остаток.

### Печать

Выбрать товары → задать количество → выбрать шаблон → предпросмотр → сформировать PDF → записать задание.

Подробные требования: `docs/crm/requirements.md`.
