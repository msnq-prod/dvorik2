# TX-204 — Inventory and reversal

## Статус
- `done`; P0; зависит от `TX-203`.

## Цель
Inventory применяет только целиком проверенный versioned snapshot; reversal атомарно и однократно отменяет допустимую original operation.

## Шаги/DoD
1. Inventory валидирует все строки и versions до первой записи; discrepancy хранит expected/actual/delta.
2. Один stale/invalid row отклоняет весь набор без balance/operation/audit/outbox/idempotency partial state.
3. Reversal повторно читает original/current balances, запрещает reversal-of-reversal и negative result.
4. Unique reversal link и conditional balance writes исключают повторную отмену.
5. Audit/outbox/correlation находятся в том же `BEGIN IMMEDIATE` UoW.
6. Focused/fault/concurrency tests, independent review и полный `check/test/build` проходят.
