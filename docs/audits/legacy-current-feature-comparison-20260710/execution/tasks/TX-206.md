# TX-206 — Schedule and swaps

## Статус
- `done`; P0; зависит от `TX-202`.

## Цель
Shift/day/assignments/version/conflicts и swap lifecycle выполняются атомарно через SQLite UoW.

## Шаги/DoD
1. Реализовать schedule/swap repository slice и shared web/Telegram services.
2. Commit повторно валидирует active users, closed day, shift/version и schedule conflicts.
3. Swap accept атомарно меняет assignments/status, отменяет siblings и создаёт audit/outbox.
4. Два concurrent accept дают один success; stale callback получает typed replay/stale response.
5. Blocked target не назначается; rollback не оставляет accepted swap без assignment/notification.
6. Focused/fault/concurrency tests, independent review и полный `check/test/build` проходят.
