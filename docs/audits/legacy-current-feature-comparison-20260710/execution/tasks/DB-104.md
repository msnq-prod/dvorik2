# DB-104 — Unit of Work

- Статус: `pending`; P0; зависит от DB-101, DB-102.
- Контуры: database adapter, UoW context, service composition, fault tests.

## Шаги
1. `UnitOfWork.transaction(callback)` выдаёт sync transaction context и repositories,
   созданные factory на том же `DatabaseContext`; concrete contracts добавляет `DB-105`.
2. Nested service принимает existing context; повторный `transaction()` внутри
   активной transaction завершается `NESTED_TRANSACTION_FORBIDDEN`.
3. Async callback завершается `ASYNC_TRANSACTION_FORBIDDEN`; escaped context после
   callback завершается `TRANSACTION_CONTEXT_CLOSED`.
4. Savepoint не экспонируется; он будет добавлен только для отдельно
   документированного partial-success process.
5. Real-SQLite fault injection после business, audit, idempotency и outbox write;
   после rollback оба connection видят нулевое состояние.

## DoD
Business/audit/idempotency/outbox commit/rollback вместе; callback не может уйти на
global connection; nested/async/escaped-context negatives и two-connection rollback tests green;
`npm run check`, `npm run test`, `npm run build` green.
