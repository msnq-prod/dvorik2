# DB-102 — Connection pragmas и readiness

- Статус: `pending`; P0; зависит от DB-101.
- Контуры: database adapter/config/health/integration tests.

## Шаги
1. На каждом connection: FK, WAL, busy timeout, synchronous, schema check.
2. Определить writer contention/retry policy и graceful close/checkpoint.
3. Readiness проверяет connection/schema/writable transaction без business rows.

## DoD
Orphan blocked, second writer ждёт policy, wrong schema/read-only DB красит ready;
connection-local pragmas доказаны на двух connections.
