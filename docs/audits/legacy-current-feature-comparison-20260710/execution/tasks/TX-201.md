# TX-201 — Common command context

## Статус
- `done`; P0; зависит от `DB-104`, `DB-105`.

## Цель
HTTP, Telegram и worker commands получают один typed context: actor, requestId,
channel, transaction-scoped repositories, idempotency key и injected clock.

## Шаги/DoD
1. Зафиксировать actor/system semantics и channel enum.
2. Context выдаётся только внутри `UnitOfWork.transaction`; raw DB не экспонируется.
3. RequestId/idempotency key валидируются до mutation; clock deterministic в tests.
4. Nested service принимает existing context.
5. Focused fake/UoW tests: web/telegram/worker/system, invalid keys, outer rollback; full gate pass.
