# TX-202 — Canonical idempotency

## Статус
- `done`; P0; зависит от `TX-201`.

## Цель
Атомарно claim `(scope,key)` с canonical request hash, status и replayable response.

## Шаги/DoD
1. Canonical JSON hash не зависит от порядка object fields и различает payload/quantity.
2. Claim/result/response/status сохраняются в том же UoW, что business mutation.
3. Same key+same payload возвращает исходный status/response без повторной операции.
4. Same key+different payload даёт typed conflict (`409`).
5. `processing` имеет timeout/recovery без takeover активного claim.
6. Focused parallel/fault/replay tests и полный `check/test/build` проходят.
