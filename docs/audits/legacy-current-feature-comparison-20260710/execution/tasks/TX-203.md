# TX-203 — Stock operation service

## Статус
- `done`; P0; зависит от `TX-202`, `DB-106`.

## Цель
Stock operation выполняет permission/idempotency/validation/balance/operation/audit/outbox в одной `BEGIN IMMEDIATE`.

## Шаги/DoD
1. Реализовать SQLite stock/product/location/audit/outbox repository slice без global `AppState`.
2. Conditional balance updates не допускают stale/negative result и operation без balance mutation.
3. Transfer запрещает одинаковые locations; reversal link уникален.
4. Zero/threshold notifications вычисляются по before→after transition.
5. Два independent writers не теряют остаток; fault injection откатывает business/audit/outbox/idempotency.
6. Focused integration/concurrency tests, independent review и полный `check/test/build` проходят.
