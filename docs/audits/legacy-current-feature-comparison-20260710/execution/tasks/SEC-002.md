# SEC-002 — Production session cookie и rotation

- Статус: `done`; P0; зависит от SEC-001, DB-105, TX-201.
- Контуры: session repository/service, HTTP auth/logout, browser tests.

## Шаги
1. `__Host-dvorik_session`, HttpOnly, production Secure, Path=/, без Domain, утверждённый SameSite.
2. Хранить token hash; rotation после login/role change; revoke старых sessions транзакционно.
3. Logout очищает cookie теми же attributes.
4. Проверить expiry/revoke между разными API processes.

## Negative/DoD
Old/raw token не работает, cookie flags подтверждены browser test, blocked/revoked
session сразу отклоняется. Не реализовывать поверх global AppState.
