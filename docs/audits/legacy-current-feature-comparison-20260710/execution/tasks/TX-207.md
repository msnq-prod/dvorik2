# TX-207 — Auth, users, roles, onboarding

## Статус
- `done`; P0; зависит от `TX-202`, `SEC-002`.

## Цель
User/status/primary-role/onboarding/session revoke/audit/outbox выполняются одной SQLite UoW transaction.

## Шаги/DoD
1. Убрать user/role/onboarding mutations и reads из process-local AppState.
2. HTTP update и Telegram approve/reject используют общий idempotent service.
3. Status/role + session revoke + audit + target outbox commit атомарно.
4. Permissions читаются из role tables; не копируются в persisted user.
5. Защитить last super admin, self-block и self-demotion.
6. Cross-process/fault/callback replay tests, independent review и полный gate проходят.
