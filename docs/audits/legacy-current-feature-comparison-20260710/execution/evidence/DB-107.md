# DB-107 evidence

Дата: 2026-07-15.

## Результат

- Production read routes используют `SqlCatalogQueryService`, а не global
  `db`: dashboard, products/search, locations, balances, operations, reports
  (JSON/CSV/PDF), inventory snapshot, schedule/day/export и audit.
- Query visibility применяется до fetch для seller schedule/day; catalog seller
  ограничен active products. SQL задаёт stable order/pagination; Unicode search
  нормализуется внутри SQLite до pagination.
- Dashboard читает notifications и delivered Telegram outbox из SQLite; два
  API-процесса видят внешнее SQL-изменение без stale AppState.

## Изменения

- `gpt-version/src/server/sqlite-catalog-query-service.ts` — production SQL
  adapter; no full-state projection, server filtering/order/limit and mapped
  corrupt-row rejection.
- `gpt-version/src/server/index.ts` — production routes select the adapter;
  legacy branch remains dev compatibility only.
- `gpt-version/src/server/database.ts` — deterministic Unicode search function.
- `gpt-version/src/server/sqlite-catalog-query-service.test.ts` and
  `session-http.test.ts` — pagination/order/empty/corrupt-row, seller negative,
  SQL visibility between two production API processes, CSV/PDF routes.
