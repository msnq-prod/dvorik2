# SEC-002 — evidence

- Дата: 2026-07-12, Asia/Vladivostok.
- Outcome security-fix workflow: `fixed`; independent reviews `accepted`.

## Изменения

- Production cookie: `__Host-dvorik_session`, HttpOnly, Secure, Path=/, SameSite=Lax, без Domain; logout использует те же attributes.
- Cookie хранит 32-byte opaque token; SQLite хранит только HMAC-SHA256. Raw session ID не является credential.
- Login rotation, authenticate, logout и user revoke работают через SQLite UoW между процессами.
- Telegram identity recheck выполняется из SQLite; role/status/onboarding revoke происходит fail-closed до legacy mutation.
- v7 удаляет legacy unhashed sessions и запрещает новые nullable hashes; AppState projection не стирает sessions/audit и scrubbed raw payload.
- Client сначала восстанавливает `/api/session` и не скрывает logout failure.
