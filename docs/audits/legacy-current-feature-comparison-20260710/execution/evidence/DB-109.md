# DB-109 evidence

Дата: 2026-07-15.

## Результат

- Production entrypoint и active workers не делают static import global `db`,
  `saveState` или `stateTransaction`.
- Legacy `AppState` bundle загружается только вне production; production
  onboarding использует отдельный SQLite-only handler.
- Telegram worker использует normalized SQLite outbox с atomic lease, retry,
  max-attempt terminal state и recovery expired lease.
- Deferred worker types не claim-ятся; disabled daily worker не открывает
  legacy store.

## Проверка

- `npm run check` — pass.
- `NODE_ENV=test npx tsx src/server/state-migration.test.ts` — pass.
- `NODE_ENV=test npx tsx src/server/sqlite-outbox-dispatcher.test.ts` — pass.
- `NODE_ENV=test npx tsx src/server/session-http.test.ts` — pass.
- `NODE_ENV=test npx tsx src/server/domain.test.ts` — pass.
- `npm run build` — pass.

## Negative / two-process

- two workers cannot dispatch the same SQLite-leased message;
- expired lease is recovered; transient delivery retries and max attempts end
  in `failed`;
- two production API processes execute Telegram onboarding while
  `app_state.payload` remains unchanged;
- source scan for production roots has no static legacy imports and no
  `db.`/`saveState`/`stateTransaction` production binding.

## Остаточный риск

Backup/restore modernization remains `EPIC-P5`; it is no longer an AppState
production import path.
