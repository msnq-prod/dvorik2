# Evidence

Evidence — воспроизводимое доказательство, а не отчёт агента о намерениях. Один файл соответствует одному ID и содержит commit/diff scope, среду, команды с результатами, ручные сценарии, артефакты, отрицательные проверки и остаточные риски. Статус `done` запрещён без evidence и проверки зависимых контрактов.
