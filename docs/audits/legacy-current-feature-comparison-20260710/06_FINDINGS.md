# Findings — первый инкремент

### P1. Получатель мог принять конфликтующую смену

- Promise: подмена безопасно назначает смену доступному сотруднику.
- Reality: доступность проверялась при создании заявки, но не при её принятии.
- Effect: сотрудник мог получить пересекающиеся смены.
- Fix: повторная overlap-проверка непосредственно перед заменой назначения.
- Status: fixed.

### P1. Главная страница дублировала меню вместо операционного dashboard

- Promise: admin видит рабочее состояние магазина после входа.
- Reality: существующий `DashboardPage` не был подключён.
- Effect: нет быстрого обзора остатков, уведомлений и движений.
- Fix: dashboard назначен `dashboard`-view, быстрые действия сохранены.
- Status: fixed.
