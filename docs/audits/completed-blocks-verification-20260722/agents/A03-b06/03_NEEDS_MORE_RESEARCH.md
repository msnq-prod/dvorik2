# A03 — B06: что требует внешней проверки

Это не дефекты, доказуемые без доступа; они относятся к отдельной внешней активации.

- Выдать реальные credentials и `pointId`, выполнить OAuth и `retail/order/list` на фактическом тарифе.
- Получить обезличенные ответы: продажа, возврат, completed → deleted/rejected/nonfiscal, изменение цены/количества/скидки. Нынешние tests используют hand-made mock (`saby-sync-service.test.ts:23-31`).
- Разместить API по публичному HTTPS URL, установить trigger и провести контрольные фискальные продажу и возврат. Это прямо зафиксировано как незавершённое в `docs/план работ/99_PROGRESS.md:46-55` и `gpt-version/docs/SABY_INTEGRATION.md:71-79`.
- Подтвердить фактические поля статусов/ревизий и pagination contract. Документация не заменяет ответ реального аккаунта.
