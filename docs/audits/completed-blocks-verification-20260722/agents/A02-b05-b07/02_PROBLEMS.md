# Подтверждённые расхождения B05/B07

### P1-A02-01: B05 отмечен как завершённый без части обязательных контуров

- **Обещание:** B05 включает отмену зависшей сессии, очередь внешних событий после закрытия, reconciliaton оперативных переносов и actual/estimated/forecast (`14_ИНВЕНТАРИЗАЦИЯ_И_РАСХОД.md:21-75,105`).
- **Реальность:** HTTP/API предоставляет только start и close (`gpt-version/src/server/index.ts:1173-1188`); `cancel` в сервисе отсутствует. Нет consumption-period ledger/reconciliation и нет API/модели estimated/forecast (поиск по `src` не нашёл их). Saby retry запускается только циклом worker, раз в успешный sync до 15 минут, и повторяет строки по `external_sale_key`, а не по времени чека: `saby-worker.ts:27-35`, `saby-sync-service.ts:180-190`.
- **Эффект:** зависшая сессия может бессрочно блокировать операции; критерии B05 о процедуре отмены и применении событий по времени чека не доказаны.
- **Статус:** confirmed, P1.

### P1-A02-02: B07 отмечен завершённым при отсутствии payroll

- **Обещание:** полный B07 включает настройки владельца, расчёт, премии, НДФЛ/взносы и результаты только для владельца (`16_РАСПИСАНИЕ_И_ЗАРПЛАТА.md:52-106,121-134`).
- **Реальность:** сама отметка исключает payroll и money fields (`99_PROGRESS.md:36-37`). Маршруты `/api/payroll`, `/api/finance`, `/api/revenue`, `/api/profit` намеренно возвращают 404 и отсутствуют в OpenAPI: `gpt-version/src/server/session-http.test.ts:390-409`.
- **Эффект:** существенная часть критериев B07 не реализована и не может быть принята.
- **Статус:** confirmed, P1.

### P2-A02-03: Смена не ограничена плановым интервалом 10:00–21:00

- **Обещание:** дневная смена строго 10:00–21:00 (`16_РАСПИСАНИЕ_И_ЗАРПЛАТА.md:25-31`).
- **Реальность:** service принимает входные `start`/`end` и проверяет только корректность интервала; профильный тест создаёт смену 09:00–17:00: `gpt-version/src/server/schedule-swap-service.test.ts:117-134`.
- **Эффект:** календарь допускает график вне согласованной модели.
- **Статус:** confirmed, P2.
