# Риски

- Отметка `[x]` применяется к частичному инкременту, тогда как детальные планы описывают полный блок. Это создаёт ложное ощущение готовности.
- Автоматический release gate подтверждает сборку и тесты, но не закрывает внешние и ручные acceptance-критерии.
- Стыки B05/B06 и B07/финансы пока не обеспечивают end-to-end сценарии полного scope.
