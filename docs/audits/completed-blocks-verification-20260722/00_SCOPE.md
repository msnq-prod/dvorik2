# Проверка заявленного завершения блоков

- **Цель:** независимо проверить отметки B02, B03, B05, B06 (code-ready), B07, B09 и B10 в `docs/план работ/99_PROGRESS.md`.
- **Проверяется:** наличие реализации, трассировка ключевых сценариев, тесты и фактический запуск проверок в `gpt-version`.
- **Не входит:** внесение исправлений, активация Saby на внешнем аккаунте и production-запуск.
- **Критерий:** статус «завершено» подтверждается только если код, тесты и заявленные границы совпадают; внешние зависимости отмечаются отдельно.
